# Plan: Curriculum Content

## Proposed Vertical Slices

1. **Opening package validates all exact content and asset dependencies**
   - Blocked by: stable MVP domain schemas, Rendering Assets #4-#5
   - Adds package/arc/scenario/guidance/Handbook schemas, dawn entities, first
     two feeding Tasks/artifacts/routes, free eval, unlocks, reward, accessible
     equivalents, and asset bundle manifest.
   - Tests: exact cross-domain references, asset readiness, unlock reachability,
     no arbitrary code, no fatal onboarding, and package fingerprint.
   - Visible proof: generated content report shows the complete opening chain.

2. **The five-minute opening runs end to end through real domains**
   - Blocked by: #1 and corresponding first-playable slices in all MVP domains
   - Adds authored timing/cues, first success, maintenance omission, near miss,
     incident text, minimum fix, free eval, review/deploy, successful open, and
     concise reward/Handbook entry.
   - Tests: golden exact outcome, no hidden guidance penalty, no prose behavior,
     causal navigation, save/reload, and instrumentation hooks.
   - Browser proof: complete unassisted baseline attempt and assisted fallback.

3. **A novel enclosure tests missing-context transfer**
   - Blocked by: #2
   - Adds new species/enclosure/surface details, same underlying routing concept,
     withheld original guidance, observable success criteria, and optional help
     only after transfer observation.
   - Tests: changed IDs/assets/route, concept-equivalent outcomes, no memorized
     path dependency, and exact success event.
   - Browser proof: solve without repeated instructions.

4. **Retention and Memory arc covers Strict, loss, compaction, and retrieval**
   - Blocked by: Context #3-#6, Memory #1-#4, Incident Response #1-#2
   - Adds context-bloat, runtime overflow, Keep Newest loss, compaction-loss,
     retrieval-miss, external recovery, comparison, transfer, and mastery scenarios.
   - Tests: exact manifests, intended behavior differences, recovery boundary,
     stable mastered rerun, and required asset/guidance references.
   - Browser proof: experience, diagnose, revise, and transfer each lifecycle concept.

5. **Eval, version, and deployment arc creates regression judgment**
   - Blocked by: Eval Runner #2-#4, Review/Deployment #1-#5, Economy #2
   - Adds degraded-sensor, stale-policy, coverage-gap, risk/cost selection,
     reusable suite, revert, and transfer scenarios.
   - Tests: real cases, exact versions, omitted-risk consequence, cheap rerun,
     history preservation, and no fake reliability.
   - Browser proof: choose coverage, diagnose a gap, revise, and revert safely.

6. **Workers and Manager arc teaches explicit orchestration**
   - Blocked by: Orchestration #1-#5
   - Adds parallel work, shared-gate conflict, specialization, vague Manager,
     explicit authority/routing/reporting/escalation, mature density, transfer,
     and calm mastery scenarios.
   - Tests: problem-before-Manager, exact cross-Agent chains, no magic fix,
     attention reduction, and optional expansion.
   - Browser proof: progress from multiple Workers to governed Manager operation.

7. **Suspension and comeback arc proves recoverable consequences**
   - Blocked by: Incident Response #4, Economy #6, Persistence #3-#5
   - Adds severe but responsible scenario, suspension copy, preserved history,
     mandated evals, restricted funding branch, compliant deploy, reopening, and
     demonstrated trust restoration.
   - Tests: exact trigger, non-exploitative presentation, no dead save, no timer
     recovery, and complete historical replay.
   - Browser proof: fail, recover, reopen, and continue the same park.

8. **Curriculum validation and playtest gate**
   - Blocked by: #1-#7, Telemetry/Playtesting slices
   - Adds content-build validation, golden scenario suite, copy/accessibility
     review, asset readiness checks, baseline protocols, and full validation.
   - Browser proof: opening, transfer, retention, eval/review, orchestration,
     suspension, stable mastery, keyboard, reduced motion, and text scaling.
