# Plan: Incident Response

## Proposed Vertical Slices

1. **A Strict-stopped robot receives an explicit response plan**
   - Blocked by: Park Operations #3-#4, Context #4, Simulation #1-#4,
     Economy #1-#2, Trace #1-#3
   - Adds eligibility, location/risk, deterministic capability plan, arrival,
     duration, cost/closure quote, unavailable reasons, and response card.
   - Tests: eligible/ineligible, exact quote, grouped incident, idempotent call,
     failed-Agent independence, and keyboard/non-color card.
   - Browser proof: inspect and activate recovery for a hazardous stopped robot.

2. **The team visibly stabilizes without touching engineering state**
   - Blocked by: #1
   - Adds dispatch/en-route/operating lifecycle, visitor evacuation, temporary
     containment, robot recovery commands, staged projections, trace evidence,
     and settlement.
   - Tests: exact tick/action order, capability/access limits, partial failure,
     world stabilization, context/artifact/deployment unchanged, and unresolved
     cause.
   - Browser proof: watch response, inspect stabilized park, follow unchanged
     responsible artifact.

3. **Explicit Agent authority can call response later in progression**
   - Blocked by: #1-#2, Orchestration authority slice
   - Adds activation authority, escalation criteria, cost permission, provenance,
     and rejected unauthorized calls.
   - Tests: worker/manager authority, thresholds, duplicate call, insufficient
     permission, cost settlement, and complete delegation trace.
   - Browser proof: compare manual and authorized automatic escalation.

4. **Operating License Suspended preserves the park and requires active recovery**
   - Blocked by: #1-#2, Economy #6, Review/Deployment #5
   - Adds exact suspension evidence, revenue/visitor stop, active-danger
     stabilization, preservation manifest, recovery review, mandated eval/deploy
     gates, restricted funding, and reopening restrictions.
   - Tests: each trigger, complete preservation, no timer recovery, insufficient
     funds, failed mandated eval, compliant reopen, reduced demand, and safe trust
     restoration.
   - Browser proof: enter suspension, inspect history, correct, eval, deploy,
     reopen, save/reload contract.

5. **Incident Response validation gate**
   - Blocked by: #1-#4
   - Adds balance/prototype instrumentation, rendered accessibility tests,
     boundary architecture lint, and full validation.
   - Browser proof: plan, call, wait, stabilize, automatic authority, suspension,
     recovery, keyboard-only, reduced motion, and sound substitution.
