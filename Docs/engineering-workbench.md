# Engineering Workbench

Phase 6 adds a deterministic Workbench domain behind `src/engineering-workbench/public.ts`. It projects exact artifact source and executable clauses separately, compares exact versions with evidence-backed semantic differences, previews bounded clause/context-route composition, and produces immutable candidates through the single Park Developer.

Candidate completion never mutates the production reference. Revision feedback creates a new linked work request. The Engineering Handbook is a player reference with canonical terms and encountered examples; every entry is permanently marked ineligible for Agent Context.

The opening fixture exposes Prompt engineering and Context optimization. Other capability categories remain visible but locked until later progression creates the required pressure.
