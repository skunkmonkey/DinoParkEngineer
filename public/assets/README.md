# Generated runtime asset boundary

Only deterministic compiler output selected from an exact, approved candidate
may be written here. Source candidates, generation prompts, secrets, rejected
work, and review contact sheets are not runtime assets.

`mvp-park/atlas.png` and `atlas.json` are the deterministic PixiJS fixture.
They expose exact IDs, atlas rectangles, transforms, pivots, hit regions, depth
hints, animation metadata, semantic tags, accessibility labels, and approved
source linkage. `platform-comparison.json` records byte-equivalent canonical
manifests from `darwin` and `win32` logical compiler inputs without claiming
access to two operating systems.
